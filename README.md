## 4核8G到底够不够用

日活一千以内的项目，4核8G基本够用。同时跑多个服务，或者Java应用和数据库挤在同一台机器上，8GB内存就会开始紧张。

8GB的好处是可以同时跑几个吃内存的服务，不用反复权衡先关哪个。具体到场景：

- **Java应用**：堆内存分4GB比较稳，剩下的留给系统和数据库。不能把8GB全设成堆上限，线程、运行时和本地内存也要占地方。
- **MySQL同机**：数据量小的时候没问题，数据一涨，查询变慢和内存告警会跟着来。
- **容器部署**：计划跑三个以上容器，8核16G更舒服。
- **突发流量**：这是最容易把4核8G打满的场景，CPU和内存都没有太多缓冲。

带宽是另一条容易被忽略的上限。4核8G的算力再强，只挂1M带宽，实际能支撑的并发一样会被卡死。选套餐时把带宽和流量放在核数前面看，通常更接近真实体验。
